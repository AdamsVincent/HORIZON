REMPLACEMENT SUR GITHUB
1. Ouvrez votre dépôt GitHub.
2. Supprimez les anciens fichiers :
   - index.html
   - styles.css
   - script.js
   - ancien dossier assets
3. Cliquez sur Add file > Upload files.
4. Déposez les nouveaux fichiers et le dossier assets.
5. Cliquez sur Commit changes.
6. Attendez une à deux minutes, puis rechargez la page du site avec Cmd + Shift + R.
